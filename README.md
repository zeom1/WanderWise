## 🌟 About The Project

**WanderWise** is a web application designed to solve the age-old problem of travel decision fatigue. Instead of endlessly scrolling through generic "top 10" lists, WanderWise takes a deeply personalized approach. 

By taking a quick interactive quiz, users uncover their core "Travel DNA" (their Primary, Secondary, and Hidden travel personalities). The app then instantly matches them with curated destinations that actually fit their travel style. 

From discovery to execution, WanderWise provides an end-to-end flow: finding your destination, estimating the budget, generating a smart packing list, and saving your bucket list entirely offline.

## ✨ Features

- **🧠 Travel Personality Quiz**: 20 interactive questions to reveal your unique Travel DNA across 10 distinct travel personalities.
- **🗺️ Destination Explorer**: Search, filter, and discover over 90 carefully curated global destinations featuring high-quality photography.
- **🎯 Smart Matching**: Instantly get "Perfect Matches", "Hidden Gems", and "Outside-Comfort-Zone" recommendations based on your quiz results.
- **💰 Budget & Savings Planner**: Estimate trip costs, set savings goals, and track your financial progress toward your next adventure.
- **🎒 Smart Packing Checklist**: Auto-generated packing lists tailored specifically to the climate and culture of your chosen destination.
- **💛 Offline Bucket List**: Save your favorite spots directly to your device using Local Storage (no account or sign-up required).
- **🎲 Surprise & Countdown Tools**: Let the app choose a random destination for you, and use the built-in countdown timer for your upcoming trip.

## 🛠️ Built With

WanderWise is built as a lightweight, lightning-fast static web application with a focus on client-side performance and zero backend dependencies.

* **HTML5** (Semantic structure)
* **CSS3** (Custom styling, Flexbox/Grid layouts, CSS variables for theming)
* **Vanilla JavaScript** (ES6+, DOM manipulation, LocalStorage integration)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You only need a modern web browser. No complex build tools, databases, or package managers are required!

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/zeom1/WanderWise.git
   ```
2. Navigate to the project directory
   ```sh
   cd WanderWise
   ```
3. Open `index.html` in your favorite web browser!
   ```sh
   # On macOS
   open index.html
   
   # On Windows
   start index.html
   ```
